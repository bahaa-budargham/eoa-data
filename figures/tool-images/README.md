
# Tool Images

Screenshots of the interactive EOA tools. The tools themselves are not stored in this repository. Each image shows a tool in use.

| File | Tool |
| :--- | :--- |
| `tool-eoa-anagram-comparator-figure1.png` | Anagram word signature comparator. Builds per-letter sequences and compares anagram sets such as own / won / now under two weighting methods. |
| `tool-eoa-beta-operator-500.png` | Beta operator sequence explorer. Selects a bijective phonetic mapping, computes the exact term sequence, shows the limiting growth rate to 200 decimals for 500-term sequence with a 249-digits final term, and counts prime terms. |
| `tool-eoa-sequence-to-json-builder-figure1.png` | Sequence to JSON builder. Takes letter sequences pasted without commas and produces a valid JSON file for use in other EOA tools. |
| `tool-eoa-term-sequence-ratio-figure1.png` | Term sequence ratio tool. Computes term-by-term ratios between any two of the 43-term letter sequences, with export to JSON and CSV. |
| `tool-eoa43-01-understanding-patterns-figure1.png` | Understanding patterns viewer. Explores structure in the EOA-43 sequences across encodings. |
| `tool-index-eoa-vector-generator-figure1.png` | Vector generator index. Generates EOA vectors for large word lists, with CSV export. |

## Notes

- All tools run client-side. No server is required.
- The 43-term sequences are the data source for every tool shown here.
- The operator that generates the sequences is not disclosed. Access is governed by the terms described in EOA Part I, Section 2.
