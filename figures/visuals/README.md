# EOA Visuals

Exploratory renderings of EOA-43 sequence behavior across phonetic encodings. These are not figures from any specific paper. They are shared to invite structural interpretation.

| Folder | Contents | Encoding |
| :--- | :--- | :--- |
| `tree-branch/` | Branching trees showing how the operator produces each term of a sequence | English modified-1 (LCR ≈ 3.037) |
| `heatmap/` | Pairwise cosine similarity heatmap among the 26 letters | English modified-2 (LCR ≈ 3.173) |
| `spirals/` | Spiral renderings of the sequences under three plotting modes | English modified-2 (LCR ≈ 3.173) |

## Notes

- The sequences used to generate these visuals are not publicly released. Access is governed by the terms described in EOA Part I, Section 2.
- The letter t sequence from the English modified-5 encoding (LCR ≈ π) is publicly available at https://github.com/bahaa-budargham/eoa-sequences.
- The operator that produces the sequences is not disclosed.
- Whether these renderings reveal structure beyond what the sequence values already show is an open question. See EOA Part 0, Question 11.1.
