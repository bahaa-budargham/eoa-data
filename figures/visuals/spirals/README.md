
# Sequence Spirals

Spiral renderings of an EOA-43 sequence under three plotting modes. All four images use the English modified-2 encoding (LCR ≈ 3.173).

| File | Description |
| :--- | :--- |
| `eoa43_spiral_fixed_ratio.png` | Fixed ratio r = 3.17386092713818. The angle step is 360°(1 − 1/r) ≈ 246.573°, held constant for every term. |
| `eoa43_spiral_log_compressed.png` | Log-compressed radius. Term values are plotted with logarithmic radius so early terms remain visible alongside later ones. |
| `eoa43_spiral_local_ratio.png` | Local-ratio mode. The angle step varies term by term, using the local ratio a(n)/a(n−1) instead of a fixed ratio. Shows how early terms deviate before the ratio settles. |
| `eoa43_spiral_tool.png` | The interactive tool that generated the three plots above. Shows the sequence input, ratio parameters, and plotting controls. |

## Notes

- The fixed ratio matches the modified-2 LCR to three decimals.
- These are exploratory renderings. Whether the spiral reveals structure beyond what the sequence values already show is an open question.
- The sequences used to generate these visuals are not publicly released. Access is governed by the terms described in EOA Part I, Section 2.
